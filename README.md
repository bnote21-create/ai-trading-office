# 🏛️ AI Trading Office (Thai & US Stock Desk)

ยินดีต้อนรับสู่ **AI Trading Office** สำนักงาน AI ผู้ช่วยเทรดหุ้นส่วนตัว รองรับทั้ง **🇹🇭 ตลาดหุ้นไทย (SET / mai)** และ **🇺🇸 ตลาดหุ้นสหรัฐฯ (US Stocks - Webull)** ออกแบบมาเป็นพิเศษสำหรับมือใหม่และนักลงทุนสไตล์ **Swing Trade** (ถือครองรอบ 2-3 วัน ถึง 2-4 สัปดาห์)

---

## 🌟 ฟังก์ชันหลักของ AI Office (ระบบสองตลาด)

1. **🔭 แผนกแมวมองสแกนหุ้น (Market Scout):**
   - **🇹🇭 ตลาดหุ้นไทย:** สแกนหุ้น SET50 / SET100 ชั้นนำ (เช่น DELTA, PTT, CPALL, AOT, KBANK, BDMS, GULF, ADVANC, TRUE ฯลฯ)
   - **🇺🇸 ตลาดหุ้นสหรัฐฯ:** สแกนหุ้นเทคโนโลยีและหุ้นเติบโตชั้นนำ (เช่น NVDA, AAPL, MSFT, TSLA, PLTR, AMD, SPY, QQQ ฯลฯ)
   - สแกนจับจังหวะความเสี่ยงต่ำ: **Trend Pullback** (ย่อแตะ EMA 20/50 ในขาขึ้น) และ **Momentum Breakout** (เบรกเอาท์พร้อมวอลุ่ม)
   - คำนวณจุดเข้าซื้อ (Entry), จุดตัดขาดทุน (Stop Loss), และเป้ากำไร (Take Profit 1, 2) แสดงเป็นสกุลเงิน `฿` (บาท) หรือ `$` (ดอลลาร์) ตามตลาด

2. **🛡️ แผนกผู้จัดการพอร์ต & เตือนจุดขาย (Portfolio Guardian):**
   - บันทึกหุ้นทั้งพอร์ตไทย (Streaming / Webull TH) และพอร์ตสหรัฐฯ (Webull US)
   - คำนวณกำไร/ขาดทุนแบบแยกสกุลเงิน (THB vs USD)
   - ส่งสัญญาณเตือนอัตโนมัติ:
     - 🚨 **Cut Loss:** เมื่อราคาหลุดจุดตัดขาดทุน (รักษาวินัย -5%)
     - 🎯 **Take Profit 1:** เมื่อกำไรถึงเป้าแรก แนะนำแบ่งขาย 50% แล้วเลื่อน Stop Loss มาบังทุน (Risk-Free)
     - 🏆 **Take Profit 2:** ปิดออเดอร์ล็อกกำไรก้อนใหญ่
     - 🔒 **Trailing Stop:** ป้องกันกำไรหดหายเมื่อราคาวิ่งขึ้นไปสูงแล้วเริ่มย่อตัว

3. **🧠 แผนกวิเคราะห์หุ้นรายตัว (AI Deep Dive):**
   - พิมพ์ชื่อย่อหุ้นตัวใดก็ได้ (เช่น `PTT`, `DELTA`, `CPALL` หรือ `NVDA`, `PLTR`) AI จะประเมินและวางแผนเทรดให้ทันที

4. **💬 แผนกแชทปรึกษา AI Office (AI Chat Consultant):**
   - พูดคุยถาม-ตอบกับ Chief AI Advisor ส่วนตัวได้อิสระ
   - ถามเจาะจงหุ้นรายตัว (AI ดึงข้อมูลราคาสด, EMA, RSI และคำนวณจุดซื้อ, Stop Loss, Take Profit ให้อัตโนมัติ)
   - ตรวจสอบสุขภาพพอร์ตหุ้นปัจจุบัน และขอคำแนะนำก่อนตัดสินใจซื้อ-ขาย
   - มีปุ่มลัดคำถามยอดนิยมสำหรับมือใหม่ใช้งานได้ในคลิกเดียว

5. **🔔 ระบบแจ้งเตือน Dual-Channel (Telegram & LINE):**
   - ส่งสัญญาณซื้อ-ขาย และเตือนพอร์ตเข้า Telegram Bot และ LINE พร้อมกันแบบเรียลไทม์

## 🚀 วิธีเริ่มต้นใช้งาน

### 1. วิธีเปิด Web Dashboard & ระบบเฝ้าพอร์ตเรียลไทม์
คุณสามารถเปิดใช้งานหน้าจอห้องทำงาน AI Office ได้ทันทีโดย:
* ดับเบิ้ลคลิกที่ไฟล์ **`start_dashboard.bat`** หรือ
* เปิด PowerShell / Command Prompt ในโฟลเดอร์นี้ แล้วพิมพ์:
  ```bash
  python -m streamlit run app.py
  ```
ระบบจะเปิดหน้าต่างเบราว์เซอร์ที่ `http://localhost:8501` โดยอัตโนมัติ
> 💡 **ระบบเฝ้าพอร์ตอัตโนมัติ (Auto-Guardian) จะทำงานทันทีในเบื้องหลัง** คอยตรวจเช็คราคาทุก 60 วินาที เมื่อราคาหุ้นตัวใดแตะจุด Stop Loss หรือ Take Profit ระบบจะส่งข้อความเข้า LINE และ Telegram ทันทีโดยไม่ต้องกดปุ่มใดๆ!

---

### 2. วิธีรันระบบเฝ้าพอร์ต 24 ชั่วโมง โดยไม่ต้องเปิดเบราว์เซอร์
หากคุณต้องการปิดหน้าเว็บ หรือปล่อยให้เครื่องเฝ้าพอร์ตตลอดคืน:
* ดับเบิ้ลคลิกที่ไฟล์ **`start_guardian.bat`**
* ระบบจะเฝ้าพอร์ตและยิง Alert อัตโนมัติทุกๆ 60 วินาทีอย่างเงียบๆ และกินทรัพยากรเครื่องน้อยมาก

---

### 2. วิธีตั้งค่าการแจ้งเตือนเข้า Telegram Bot (แนะนำมากที่สุด: เสถียร ฟรีตลอดชีพ)
1. เปิดแอป **Telegram** แล้วค้นหา `@BotFather`
2. ส่งข้อความ `/newbot` -> ตั้งชื่อบอทของคุณ เช่น `MyTradeOfficeBot` -> ตั้ง username ของบอทที่ลงท้ายด้วย bot เช่น `my_us_stock_trade_bot`
3. บอทจะให้ **HTTP API Token** มา เช่น `7123456789:AAH...` (คือนำมาใส่ใน `TELEGRAM_BOT_TOKEN`)
4. ค้นหา `@userinfobot` หรือ `@getmyid_bot` บน Telegram แล้วกดปุ่ม **Start** เพื่อดูเลข **ID** ของคุณ เช่น `123456789` (คือนำมาใส่ใน `TELEGRAM_CHAT_ID`)
5. **สำคัญ:** กดเข้าไปที่บอทที่คุณสร้างขึ้นมาในข้อ 2 แล้วกดปุ่ม **Start** หนึ่งครั้ง เพื่อเปิดใช้งานการรับข้อความ
6. นำข้อมูลมาใส่ในไฟล์ `.env` ในโฟลเดอร์นี้:
   ```env
   TELEGRAM_BOT_TOKEN=7123456789:AAH...
   TELEGRAM_CHAT_ID=123456789
   ```

---

### 3. วิธีตั้งค่าการแจ้งเตือนเข้า LINE (ฟรี)
1. ไปที่เว็บไซต์ **LINE Notify**: https://notify-bot.line.me/
2. ล็อกอินด้วยบัญชี LINE ของคุณ แล้วไปที่เมนู **My Page (หน้าของฉัน)**
3. กดปุ่ม **Generate token (ออก Token)** -> ตั้งชื่อบอท เช่น `AI-Trading-Desk` -> เลือกว่าจะให้ส่งเตือนเข้าแชทส่วนตัวของคุณ (1-on-1 chat)
4. คัดลอกรหัส Token ที่ได้ มาใส่ในไฟล์ `.env` ในโฟลเดอร์นี้:
   ```env
   LINE_NOTIFY_TOKEN=รหัสโทเค็นของคุณที่นี่
   ```

---

### 4. วิธีเปิดใช้งาน AI ขั้นสูง (Gemini API - ฟรี)
หากต้องการให้ AI วิเคราะห์ข่าวและสรุปคำแนะนำเชิงลึกเป็นภาษาพูด:
1. ไปที่ **Google AI Studio**: https://aistudio.google.com/
2. ล็อกอินด้วยบัญชี Google แล้วกด **Get API key**
3. นำรหัส API Key มาใส่ในไฟล์ `.env`:
   ```env
   GEMINI_API_KEY=รหัสคีย์ของคุณที่นี่
   ```
*(หากยังไม่ได้ใส่ Key ระบบจะยังคงวิเคราะห์กราฟด้วยสูตรคณิตศาสตร์และ Technical Indicators ระดับมืออาชีพได้ตามปกติ)*

---

### 4. วิธีรันระบบเฝ้าตลาดอัตโนมัติในเบื้องหลัง (Background Daemon)
หากคุณต้องการให้ AI คอยเฝ้าพอร์ตและตรวจตลาดอัตโนมัติตลอดเวลา:
```bash
python run_office.py --daemon
```
หรือสแกนด้วยตนเองครั้งเดียว:
```bash
python run_office.py --scan             # สแกนหาหุ้นน่าซื้อ
python run_office.py --check-portfolio  # ตรวจเช็คพอร์ตและสัญญาณขาย
```

## 📱 เคล็ดลับการเทรดบนแอป Webull สำหรับมือใหม่

1. **เวลาเปิด-ปิดตลาดหุ้นสหรัฐฯ (เวลาประเทศไทย):**
   - **ช่วงปกติ (ฤดูร้อน):** 20:30 น. - 03:00 น.
   - **ช่วงฤดูหนาว (พ.ย. - มี.ค.):** 21:30 น. - 04:00 น.
   - *คำแนะนำ:* คุณสามารถดูบทวิเคราะห์จาก AI Office ช่วง 19:00 - 20:00 น. แล้วเข้าไปตั้งคำสั่งซื้อขายล่วงหน้าบน Webull ได้เลย ไม่จำเป็นต้องอดนอนเฝ้าจอ

2. **การตั้งคำสั่ง TP/SL (Take Profit / Stop Loss) บน Webull:**
   - เมื่อกดปุ่ม **Trade** ใน Webull เพื่อซื้อหุ้น ให้เปิดแถบ **Take Profit / Stop Loss**
   - นำตัวเลข **Stop Loss** ที่ AI คำนวณให้ไปใส่ในช่อง Stop Price
   - นำตัวเลข **Target 1** ไปใส่ในช่อง Limit Price
   - วิธีนี้จะช่วยปกป้องเงินทุนของคุณโดยอัตโนมัติ 100% แม้คุณปิดแอปไปนอนแล้ว
